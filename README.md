# 🎵 Discord Music Bot

Bot Discord Music sederhana yang dibuat untuk pembelajaran dan eksperimen oleh siswa **PPLG SMK Annur**.
Project ini bersifat **open public** agar siapa pun bisa belajar, mengembangkan, atau memberi kontribusi.

---

## 📌 Tentang Project

Bot ini memungkinkan server Discord memutar musik melalui voice channel dengan perintah sederhana.
Tujuan utama project:

* Media pembelajaran pemrograman
* Eksperimen fitur bot Discord
* Berbagi source code secara terbuka

> ⚠️ Project ini dibuat untuk edukasi. Gunakan dengan bijak.

---

## ✨ Fitur Utama

* ▶️ Play musik dari URL / query
* ⏸ Pause / Resume
* ⏹ Stop musik
* ⏭ Skip lagu
* 📃 Queue list
* 🔊 Join & Leave voice channel

*(Fitur bisa berbeda tergantung update repo)*

---

## 🛠️ Persyaratan

Pastikan sudah install:

* Node.js (disarankan v18+)
* npm
* Akun Discord
* Discord Bot Token

---

## 🚀 Cara Setup (Simple Tutorial)

### 1️⃣ Clone Repository

```bash
git clone https://github.com/USERNAME/REPO-NAME.git
cd REPO-NAME
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Konfigurasi Bot

Buat file `.env` atau edit config sesuai project:

Contoh:

```
TOKEN=ISI_TOKEN_BOT_KAMU
```

---

### 4️⃣ Jalankan Bot

```bash
node src/index.js
```

Jika berhasil, bot akan online di Discord ✅

---

## 🤖 Cara Membuat Bot Discord (Singkat)

1. Buka Discord Developer Portal
2. Buat Application baru
3. Masuk tab **Bot → Add Bot**
4. Copy Token
5. Invite bot ke server dengan OAuth2 URL Generator
